Phase 1: Preprocessing

Data Ingestion, Tokenization & POS Tagging

Before training begins, raw corpora splits must be aligned into a structured format. We run NLTK tokenizers to find word boundaries, assign word-level POS tags (using Penn Treebank tags), tokenize via the BERT WordPiece tokenizer, and cache the datasets locally as HuggingFace Arrow tables.

Phase 2: Masking Strategy

Pretraining Masking Rules: 80% / 10% / 10%

During pretraining collations, we apply dynamic masking to the input tokens. Specifically, 15% of the WordPiece tokens are selected for MLM target calculations. For each selected token, the collator applies the standard 80/10/10 rule:

80%
[MASK] Token
Replace with masked token
10%
Random Token
Replace with random vocab token
10%
Unchanged
Keep the original token word

80% Replaced with [MASK] token

Forces the encoder to learn semantic reconstruction embeddings on the masked index.

BERT & Encoder-Only architectures

Bidirectional Attention vs. Causal Blockers

Unlike decoder-only models (like GPT) which use causal masking to restrict tokens to only attend to the left, BERT is an encoder-only model. It uses bidirectional self-attention, allowing every token to attend to context on both the left and right. Pretraining Optimization

Multi-Task Cross Entropy Loss Calculations

Our model optimizes parameters over multiple pretraining tasks. In standard Multi-Task pretraining, the total loss aggregates semantic cross-entropy, sentence contiguous classifications, and syntactic POS tagging losses:

Total Loss = L_MLM + L_NSP + alpha * L_POS
1. Masked Language Modeling Loss

L_MLM = -1/N * sum( log P(x_i | context) )

Computes cross-entropy on masked subwords. Restores hidden tokens.

2. Next Sentence Prediction Loss

L_NSP = -[y*log(p) + (1-y)*log(1-p)]

Binary classification checking context continuity between sentence pairs.

Gradients & Backprop

MultiTaskBERT Gradients Flow

During the backward pass of MultiTaskBERT, gradients from the three independent tasks converge. Gradients from the POS loss propagate backward through the pooling layers. Using the chain rule:
dL / dH_seq = P^T * dL / dH_word

Thus, the transpose of the pooling matrix $P^T$ acts as a gradient distributor, sharing the word-level syntactic error signals back to each of its constituent subwords. Click "Trigger Backpropagation" below to watch the gradient flow animated.

Layered Pretraining

Vocabulary Restriction Mechanics

Predicting 1-out-of-30,522 vocabulary tokens represents high prediction entropy. However, grammatical constraints specify that the masked slot in "the [MASK] sat" MUST be a noun. The Layered POS architecture predicts POS tags first, then maps the tag to its allowed vocabulary subset, adding log masks to force invalid word logits to negative infinity.

MaskedLogits = RawLogits + log( vocab_mask + epsilon )
Gradients & Backprop

LayeredPOSMLMBert Dual Gradients Flow

In the Soft Layered Masking mode, the vocab mask is computed dynamically as the dot-product of predicted POS probabilities and the allowed vocabulary matrix. This makes the mask fully differentiable! Consequently, gradients from the MLM semantic loss propagate backwards through the log-combination overlay and directly into the POS Tagging Head, co-tuning both heads. Key Takeaways

Pretraining Architecture Review

Our experiments show that combining multi-task pretraining with structural syntax alignment regularizes representation learning, leading to faster convergence and stronger performance on syntactic and semantic evaluations within strict low-resource boundaries.

✅ Subword Pooling

Dynamically averaging subwords into word vectors allows the base encoder to benefit from both fine-grained subword semantics and word-level syntax constraints.

✅ Layered Vocab Filters

Overlaying POS prediction filters onto logits reduces prediction entropy, enabling robust vocabulary convergence even under strict small-data budgets.
